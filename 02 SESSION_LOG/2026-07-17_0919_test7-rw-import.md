## DECISIONS

- **Module boundary detection via Q1 positions:** Instead of using the "Module N RW" header
  line as the start of each section, detect the true section start by finding the first valid
  standalone '1' that isn't after 'Module' or 'CONTINUE'. For T7 this correctly identifies
  page 4 (M1 Q1) and page 20 (M2 Q1) as section starts, matching the physical PDF layout.
  This fix should be carried forward for T8-T11 extractions (each test should be verified
  before assuming the same structure).

- **M2-Q23 manual injection:** The number '23' is missing from the extracted text for M2's
  Q23. The text block is unambiguously bracketed by Q22 (line 1476) and Q24 (line 1504).
  Hard-coded `m2_q[23] = 1490` in the parser.

- **Right-column chart support:** Added `left_col=False` parameter to `extract_drawings_in_column`.
  The check is now: `r.x0 >= page_w/2 - 20` for right column vs `r.x0 < page_w/2 + 20` for left.
